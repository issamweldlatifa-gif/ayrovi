# QATAFO — Universal Shopping & Visual AI Platform v2.5

منصة **QATAFO** للشراء بالوكالة من المتاجر العالمية الكبرى (**SHEIN**, **Amazon**, **TEMU**, **AliExpress**, **Zara**, **Nike**) والتوصيل حتى باب المنزل في **تونس** مع الدفع بالدينار التونسي (TND) وسعر الصرف المعتمد **(1 EUR / USD = 4.00 DT)**.

---

## 🌟 الميزات التقنية الرئيسية

1. **محرك الذكاء الاصطناعي البصري لقراءة لقطات الشاشة (Screenshot OCR AI) :**
   - رفع لقطة شاشة لأي سلعة من الهاتف ➔ استخراج السعر الأصلي غير المخفض في ثانية واحدة.
   - قراءة سلال المشتريات والتوجه للمجموع الكلي السفلي للطلب.
2. **محول الأسعار المباشر بالدينار التونسي (1 EUR = 4.00 DT) :**
   - حساب السعر الأصلي + الشحن الدولي والديوانة + التوصيل الداخلي بشفافية.
3. **محرك استخراج الروابط المباشر (Smart Link Scraper) :**
   - استخراج بيانات السلعة وتفاصيلها من الرابط المباشر.
4. **سلة المشتريات وإتمام الطلب (`/cart`) :**
   - سلة مركزية موحدة واستمارة توصيل للولايات الـ 24 وتوليد رقم تتبع رسمي `QTF-2026-XXXX`.

---

## 🚀 خطوات النشر على Render.com في 3 دقائق:

1. أنشئ حساباً على **[GitHub.com](https://github.com)** وارفع هذا المشروع في مستودع جديد (Repository).
2. ادخل على **[Render.com](https://render.com)** واضغط **`New +`** ➔ **`Web Service`**.
3. اختر مستودع المشروع واضبط الإعدادات:
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
4. اضغط **`Create Web Service`** وسيعمل موقعك مع قارئ الصور والذكاء الاصطناعي أونلاين فوراً!
